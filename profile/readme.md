#### Keeping the tracker current

- Keep one row per app with its name, short description, category, contributors and status.
- Use **Idea → In development → Ready to submit → Waiting for review → In review → Released**, or **Paused**.
- Record the version/build and date when a review status changes. Keep the released version visible while an update is in review.
- Only mark an app **Released** when it is available on the App Store; approval alone is not release. Add its verified App Store link when available.
- Mark an unverified category **To confirm**. A planned category is not a confirmed App Store assignment.
